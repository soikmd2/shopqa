# Glossário

| Termo | Definição |
|-------|-----------|
| Subtotal | Soma de preço × quantidade de todos os itens do carrinho, sem descontos e sem frete. |
| Base | Subtotal menos o desconto do cupom (RN-20). É sobre a base que se calcula frete grátis e desconto PIX. |
| Valor cobrado | Valor efetivamente debitado do cliente (deve ser igual ao total do pedido). |
| Minicarrinho | Atalho no cabeçalho com a quantidade de itens e o subtotal do carrinho. |
| Cupom de frete | Cupom cujo benefício é zerar o frete (ex.: FRETEGRATIS). |
| Bloqueio de conta | Período em que o login é recusado mesmo com senha correta (RN-28). |
| Idempotência | Propriedade de uma operação que, repetida, produz o mesmo efeito que uma única execução. |
